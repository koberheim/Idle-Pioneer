# Music

Tracks are chosen by context with `Sfx.set_music_context(id)`, which crossfades
to `<id>.ogg` (or `.wav` / `.mp3`) in this folder, falling back to `theme`:

| id | plays |
|---|---|
| `theme` | New World map, Workshops, Ledger (looped) |
| `europe` | Europe tab (looped) |
| `congress` | Congress tab (looped) |
| `independence` | once, when the Declaration is signed, then back to the previous track |

Loops are set in code, not in the import settings. If no file exists at all,
the original folk-style loop synthesised by `scripts/core/sfx.gd`
(`_build_music`) plays instead. Music can be toggled in the in-game Settings.

The .ogg files are generated by `tools/music/compose.py`; see
`../CREDITS.md` for tunes and licenses.
